# Mess Manager logo

Design B, "Ribbon UM" (founder approved 2026-10-27). The teal U stands for Uyoon Tech Solutions, the golden M for Mess Manager, and the "=" for equal, fair shares.

- Background: #0F3550 → #061826 (splash and adaptive fallback colours: #0A2233, #0B2A40)
- Teal: #5EEAD4 → #0E7490
- Gold: #FFE08A → #F59E0B
- Name font: Plus Jakarta Sans ExtraBold (800)

The app icon has no text: the phone shows the app name under it. Use the logo with the name only on the website, PDFs and letterheads.
