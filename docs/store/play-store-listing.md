## 2. Store texts

### English
**Short description (≤80):**
Share room and mess expenses fairly. Every expense visible, proved and settled.
*(79 characters)*

**Full description:**
Mess Manager keeps the shared expenses of a flat, hostel, mess, office or friends group in one clear, honest record.

Create a Room, invite members with a code, and add every expense — who paid, how much and who shares it. Mess Manager works out who owes whom and suggests the fewest payments to settle up.

WHY ROOMS TRUST IT
• Every change is recorded: edits and deletions stay visible in the history
• Payments need proof and Admin confirmation, so "I already paid" is easy to check
• Months lock after settlement, so old records cannot be quietly changed
• Raise a flag if something looks wrong; the Admin reviews it openly

MADE FOR EVERY ROOM
• Any currency, any time zone
• English, العربية, اردو and हिन्दी, with full right-to-left support
• Works offline — entries sync when you are back online
• Need Requests: tell the Room what is needed (gas, rice, cleaning) and see who takes it
• PDF and CSV reports with a reference number anyone can verify
• Phone notifications for payments, settlements and Need Requests

YOUR DATA, YOUR CHOICE
• Only approved Room members see the Room's records
• Download all your data or delete your account from Settings
• Mess Manager does not hold or move money — it is a shared notebook
• Small banner ads keep it free; remove them with an optional subscription

Mess Manager is for users aged 18 and over.

## 5. Data safety form

**Does the app collect or share user data?** Yes.
**Is all data encrypted in transit?** Yes (HTTPS/TLS to Supabase, Google, Expo).
**Can users request deletion?** Yes — in the app and at the deletion URL.
**Independent security review (MASA)?** Not yet (optional).

| Data type (Play category) | Collected | Shared* | Optional? | Purpose |
|---|---|---|---|---|
| Personal info → **Name** | Yes | No | Required | App functionality, Account management |
| Personal info → **Email address** | Yes | No | Required | App functionality, Account management, Developer communications (statements, deletion emails) |
| Personal info → **Other info** (date of birth — age check) | Yes | No | Required | App functionality (18+ check), Fraud prevention/compliance |
| Personal info → **User IDs** | Yes | No | Required | App functionality, Account management |
| Financial info → **Purchase history** (ad-free subscription status) | Yes | No | Optional | App functionality |
| Financial info → **Other financial info** (expense amounts, settlements, payment records entered by users) | Yes | No | Required | App functionality |
| Photos and videos → **Photos** (receipts, payment proofs) | Yes | No | Optional | App functionality |
| Files and docs (PDF receipts/proofs) | Yes | No | Optional | App functionality |
| App activity → **Other user-generated content** (notes, Need Requests, dispute text) | Yes | No | Optional | App functionality |
| App activity → **App interactions** | Yes (AdMob SDK) | Yes → Google (ads) | Required in the free app | Advertising, Analytics (by the SDK) |
| Location → **Approximate location** (from IP, by AdMob SDK) | Yes (AdMob SDK) | Yes → Google (ads) | Required in the free app | Advertising |
| Device or other IDs (advertising ID by AdMob; push token) | Yes | Yes → Google (ads) | Required | Advertising, App functionality (notifications) |
| App info and performance → **Crash logs / Diagnostics** | Yes (AdMob SDK; Sentry later without personal data) | Yes → Google (ads SDK) | Required | Analytics, App functionality |

\* "Shared" in Play's meaning = sent to a third party for its own use. Service providers that process data only for us (Supabase, email service, Expo/Firebase push) are **not** "sharing". Financial data, receipts, Room names and expense details are **never** shared with advertisers (PRD §19.3).

**Things to re-check at submission time:**
- Google's current AdMob Data safety guidance (it changes) and the exact SDK version in the build.
- If Sentry is added (v1.0): add Crash logs/Diagnostics as collected, not shared.
- If Google Sign-In is enabled: no change (email/name already declared).
