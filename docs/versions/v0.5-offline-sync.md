# v0.5 — Offline Mode & Safe Sync

**Status:** todo
**Goal:** App works on patchy networks without losing or duplicating money data (§17).

## In scope
- Local SQLite cache for Rooms, expenses, balances, history (offline read)
- Outbox queue with idempotency keys for: add/edit/delete own expense, Need Requests, payment claims with proof
- Server re-validation (permissions, 30-min window, lock) using server time only
- Late-entry move to open cycle when original cycle locked meanwhile
- Conflict handling: earlier server-accepted change wins; loser returned for review
- "Waiting to sync" badges, failure reason + retry; "Estimated — not yet synced" balances
- Background resumable receipt upload; logout/deletion warning with unsynced items
