# v0.2 — Settlement, Lock & Payments

**Status:** done — merged to main, tag v0.2.0
**Goal:** Full money loop: cycles, pro-rated settlement, month lock, payment claims with proof and Admin confirmation.

## In scope
- Settlement cycle setting (Daily/Weekly/Monthly), cut-offs computed server-side in Room time zone
- Active stay periods (join/leave dates, both days count); split "equal, pro-rated by stay" (default) and "selected members"
- Settlement generation (Edge Function) → per-member share, paid, payable/receivable, status
- Cycle lock enforced in DB (triggers); adjustment entries in open cycle linked to original
- Receipt upload (camera/gallery, JPG/PNG/PDF ≤10 MB, compressed) to private bucket, signed URLs
- Payment claim: amount, method, mandatory proof for non-cash; statuses Pending/Awaiting/Partially Paid/Paid/Rejected
- Admin confirm/reject (reason), direct record, no self-confirm; single-Admin "self-confirmed" label
- Carried-forward dues; currency-change rule (§8.2) and time-zone-effective-next-cycle rule (§8.3)
- Leaving a Room (stay ends), rejoin needs approval; Room delete rule
- "Who pays whom" minimal transfers (Could)

## Out of scope
PDF emails on leaving (v0.6), notifications (v0.3).
