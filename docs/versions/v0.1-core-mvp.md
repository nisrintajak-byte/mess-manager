# v0.1 — Core MVP

**Status:** in-progress
**Goal:** Smallest working app: users sign up, create/join a Room with Admin approval, add expenses split equally, and see who owes what. English only, but translation-ready.

## In scope
- Expo (React Native, TypeScript strict) app; runs on Android phone (Expo Go) and web preview
- Supabase project: Postgres + RLS, Auth (email/password, email verification)
- Signup: name, email, password (min 8), confirm, DOB stored, mandatory Privacy/Terms consent (version + timestamp stored)
- Login, logout, forgot password, 5-fail/15-min lock (Supabase setting)
- Room create: name, country → auto currency (ISO 4217 + decimals) → time zone (IANA); plain-text lists, no flags
- Join by Room Code; join request → Admin approve/reject; multiple Admins; Last Admin rule
- Expenses: title, amount (integer minor units), category, date, paid by, notes; split = equal among active members
- Edit/delete own expense within 30 min (server clock); Admin any; soft delete
- Append-only audit history (DB-enforced: no UPDATE/DELETE)
- Room balances screen (paid vs share vs net)
- i18n infrastructure (all strings in `en.json`), light theme
- GitHub Actions CI: typecheck, lint, unit tests

## Out of scope
Settlement cycles/lock, payments, receipts, notifications, disputes, other languages, Google Sign-In, offline, reports, ads, deletion lifecycle.

## Acceptance criteria
- Two test users can sign up, verify email, one creates a Room, the other joins and is approved
- Expense split totals equal the expense exactly in KWD (3), USD (2), JPY (0)
- Non-member cannot read any Room data (RLS test passes)
- Member cannot edit own expense after 30 min; audit rows cannot be updated/deleted
- CI green on main
