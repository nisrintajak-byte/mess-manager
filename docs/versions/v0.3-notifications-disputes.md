# v0.3 — Notifications, Disputes & Need Requests

**Status:** todo
**Goal:** Everyone is told about every money event, can flag mistakes, and can coordinate purchases.

## In scope
- Expo Push + in-app notification inbox (fallback) for all §14 events; mandatory events can't be switched off
- Notification preferences in Settings
- Settlement acknowledgement: Delivered / Seen / Pending per member for Admins
- Dispute & flag system (§12): reasons, note, evidence, "Under dispute" badge, Admin resolution rules, statuses
- Need Requests (§13): create, accept, complete → one-tap expense, cancel
