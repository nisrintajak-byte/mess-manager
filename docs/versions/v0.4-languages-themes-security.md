# v0.4 — Languages, Themes, Google Sign-In & App Lock

**Status:** in-progress (built; founder test pending at /next/; Google needs founder's OAuth client)
**Goal:** The app feels global and neutral: 4 languages with RTL, 4 themes, Google Sign-In and device privacy.

## In scope
- Arabic, Urdu, Hindi translation files; language picker before login (own script, no flags)
- Full RTL for Arabic/Urdu (mirrored navigation, numbers in RTL text); optional Eastern Arabic digits
- Fonts: Nastaliq (Urdu), Devanagari (Hindi)
- 4 themes incl. light & dark, WCAG contrast, respects system font size
- Google Sign-In (name, email, picture only); safe account linking (password once); optional app password later
- App Lock: PIN / biometric, on open and after 5 min background; re-auth for sensitive actions
- Member privacy: email visible to Admins only
