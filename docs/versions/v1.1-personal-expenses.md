# v1.1 — Personal expenses

**Status:** built, ready for testing (branch `version/v1.1-personal-expenses`). Release: first app
update after v1.0 is live on Google Play (founder 2026-11-08). Not merged into v1.0.

**Goal:** every member can keep their own spending list in the app, completely separate from
Room expenses.

## What the member gets
- New bottom tab **My expenses** (Home · My expenses · Inbox · Me).
- One month at a time: total spent (per currency — different currencies are never added
  together), number of entries, a by-category bar list, entries grouped by day. Arrows move
  to earlier months (not past the current one).
- Add / edit / delete an entry: title, amount, currency (last used is remembered; Room
  currencies and any ISO code can be picked), optional category (food, travel, bills &
  recharge, shopping, health, education, other), date (today / yesterday / any date, not in the
  future), optional note.
- The owner can edit or delete an entry at any time (no 30-minute lock — nothing is shared).
- "Download my data" (PDF and JSON) includes the list.
- 4 languages (AR/UR/HI drafts for translator review).

## Privacy and separation
- Own table `personal_expenses`; no link to Rooms, cycles, settlements, notifications, reports
  or the audit log, so Room members and Admins can never see it.
- RLS: a member reads only their own rows; no direct writes. Writes only through
  `save_personal_expense` / `delete_personal_expense` (checked on the server).
- Account deletion (app or web) erases the list at once (trigger on `profiles.deleted_at`).
- Switch: `PERSONAL_EXPENSES_ENABLED` in src/config.ts hides the tab and screens.
